INSIGHT

The schematic now mirrors a real board: a 3-way input combiner (isolation resistors on each leg, same idea as the Splitter/Combiner discussed earlier) feeding the LPF, and each shunt node split into 3 parallel physical capacitors rather than one -- real designs do this purely for current handling at high power, not to add filter order. A real reference unit uses 220/68/47pF at the input node and 180/68/56pF at the output node (asymmetric, not equal like the textbook g-values) -- that asymmetry almost certainly comes from tuning against real parasitics, which this calculator's ideal formulas can't reproduce.

INSIGHT

This design point (5-pole, 1.2x f0 cutoff, 28dB notch at 2f0) clears -50dBc on every harmonic 2f0-5f0, with margin -- the tighter cutoff and higher order do the broadband work at 3f0/4f0/5f0, and the notch handles 2f0, which stays the hardest one since the source itself is weakest there (-5.7dBc). Loosen the cutoff back toward 2x f0 or drop to 3-pole and watch 3f0 fail again -- that's the same tradeoff as before, just moved to a point that actually meets spec.
